# ScanGoQR 0.1.1

Aplicación web progresiva para crear QR de texto o URL, descargarlos como JPEG o PDF y conservarlos localmente.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta**, conservando las carpetas `icons` y `vendor`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/(root)` y pulsa **Save**.
6. Abre la dirección que GitHub mostrará después de unos minutos.

## Instalar en Android

Abre la dirección publicada con Chrome. Pulsa el icono de instalar de la cabecera o el menú ⋮ y elige **Instalar aplicación** / **Agregar a pantalla principal**.

Los datos quedan en el navegador del dispositivo. Borrar los datos de Chrome también borra los QR guardados. Los QR sin la casilla **Conservar** se eliminan al cumplir 24 horas.
